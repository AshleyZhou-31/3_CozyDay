Week of Sept 15, 2026 — Rishabh

- `planitem_list_manual` (HttpResponse FBV): `/planitems/manual/` manually
  loads and renders the PlanItem list template, then wraps it in HttpResponse.
- `planitem_list_render` (render shortcut FBV): `/planitems/render/` queries
  PlanItem records and passes them to the same template with render().
- `PlanItemListBaseView` (base View CBV): `/planitems/cbv-base/` implements
  get(), queries PlanItem records, and renders the shared template.
- `PlanItemListView` (generic ListView CBV): `/planitems/cbv-generic/` uses
  Django's model-backed ListView and the shared template.
- All four routes are named in planner/urls.py and show the same PlanItem
  data. Browser evidence: ../screenshots/section2/.
- Comparison: HttpResponse makes each rendering step explicit and is useful
  for learning or unusual response handling; render() is shorter for a
  standard template response. A base View gives control over request methods,
  while ListView removes boilerplate for a conventional model list.
